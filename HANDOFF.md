# Python Learning Journey — Handoff

## Student and Learning Style

- Learner: 8 years old and programming for the first time.
- Language: Python in Jupyter notebooks.
- Teaching style: short explanations, small runnable examples, playful practice, hints, and optional answers.
- Pace: one small topic at a time. Review earlier ideas often.
- Rule: do not treat a generated lesson as mastered until the learner has practiced it.

## How to Use This File

This file is the map for a series of workbooks. Update it after each learning session.

Use these status labels:

- `PLANNED` — not yet included in a workbook.
- `READY` — lesson and practice are prepared.
- `LEARNING` — the learner has started the topic.
- `PRACTICED` — the learner completed the main practice.
- `CONFIDENT` — the learner can use the idea with little help.
- `REVIEW` — revisit this topic in a future workbook.

Creating a workbook changes a topic to `READY`, not `CONFIDENT`.

## Workbook Design Rules

Future workbooks should:

1. Assume the learner is young and may need help typing.
2. Introduce only a few new ideas at a time.
3. Use plain language before technical vocabulary.
4. Keep code cells short and focused.
5. Include examples the learner can safely change.
6. Provide practice after every new topic.
7. Put hints before optional solutions.
8. Avoid executed `input()` cells during full-notebook validation.
9. Include review questions from earlier workbooks.
10. Finish with a playful project that combines the new skills.
11. Execute every workbook from top to bottom before delivery.
12. Update this handoff after creating a workbook or completing a learning session.

## Suggested Session Routine

For a 20–30 minute session:

1. Spend 5 minutes reviewing one familiar example.
2. Spend 10 minutes learning one new idea.
3. Spend 10 minutes changing or building something playful.
4. End by asking the learner to explain one line of code in their own words.

Stop while the learner is still enjoying it. It is better to return curious than exhausted.
